# Everlasting Summer Access 0.9.1

Still a test release; please report anything that doesn't work.

Run **EverlastingSummerAccessInstaller.exe** to install, update or uninstall. Close the game first. The full guide, with every key, is in the README on the GitHub page and in the zip.

## Changes since 0.9.0

- New standalone installer. It finds your Steam copy of Everlasting Summer, installs, updates and uninstalls the mod, and removes the older Tolk mod's files. It replaces install.ps1.
- For a manual install, **EverlastingSummerAccess.zip** now holds the mod's files in a `game` folder, ready to merge into the game's folder.

# Everlasting Summer Access 0.9.2

Run **EverlastingSummerAccessInstaller.exe** to install or update. Close the game first. You can still install by hand from the zip; see the README.

## Changes since 0.9.1

- When the main menu has been read, the mod tells you if a newer version is out, without cutting off what's being read. Run the installer to update. R repeats it until the story starts.
- The README now has a developer section, the GitHub issues link and the installer credit, and the Ko-fi link reads "Support shaysters".

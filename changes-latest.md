# Everlasting Summer Access 0.10.2

Run **EverlastingSummerAccessInstaller.exe** to install or update. Close the game first. You can still install by hand from the zip; see the README.

## Changes since 0.10.1

- Save and load slots read the date cleanly. Before, the month came out with a stray code in front of it, such as "{#month}November".
